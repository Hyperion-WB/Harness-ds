# DeepSeek Harness GUI Desktop Client

[中文](README.md) | English

**DeepSeek Harness GUI** is a native cross-platform desktop shell built for the official [DeepSeek Harness (`dsh web`)](https://github.com/deepseek-ai/deepseek-harness) powered by Tauri 2 and React 19.

---

## ✨ Key Features

- **Native Desktop & Apple-style UI**: Fluid physics sliding pill tabs, translucent glassmorphism, Dark/Light/Auto themes, system tray integration, single instance enforcement, and window state persistence.
- **Unified Multi-Vendor LLM Gateway**: DeepSeek Official (V4-Flash, V4-Pro, V3, R1), SiliconFlow, Ollama (local offline, keyless), OpenRouter, Aliyun Qwen, Moonshot, Zhipu, Anthropic Claude, OpenAI, and custom API endpoints.
- **Curated Plugin Marketplace & 286+ Radar Sync**: 1-click sync from remote radar, intelligent auto-classification (Official, UI, Agent, Dev, MCP), and 1-click upgrade.
- **1-Click MCP Server Templates**: Filesystem, Git, Web Fetch, Memory Knowledge Graph, SQLite, Puppeteer, etc.
- **Agent Preset Switcher**: Standard, PTC Code Mode SDK, Minimal, and Cordis Preset Authoring.
- **Developer Workflow Tools**: VS Code / Cursor / Terminal / File Manager quick actions, ⌘K Command Palette, Live Logs console, and hot runtime reloading.

---

## 🚀 Quick Start

```bash
git clone https://github.com/Hyperion-WB/Harness-ds.git
cd Harness-ds
pnpm install
pnpm desktop:dev
```
